# Мини-Склад

Учебный проект на платформе 1С:Предприятие 8.3.

## О проекте

Мини-конфигурация для базового учёта поступления и реализации товаров. Проект создан в учебных целях для изучения разработки конфигураций 1С и работы с Git.

## Состав конфигурации

### Справочники
- **Товары** — наименование, артикул, единица измерения.
- **Контрагенты** — наименование, ИНН, телефон, электронная почта.

### Документы
- **Поступление** — регистрация поступления товаров.
- **Реализация** — регистрация реализации товаров.

## Как открыть проект

1. Установить платформу 1С:Предприятие 8.3.
2. Создать пустую локальную информационную базу.
3. Открыть базу в режиме «Конфигуратор».
4. Выполнить загрузку конфигурации из файлов через меню «Конфигурация».
5. Обновить конфигурацию базы данных.
6. Запустить базу в режиме «1С:Предприятие».

## Структура репозитория

- `src/` — выгрузка конфигурации в файлы.
- `README.md` — описание проекта.
- `.gitignore` — исключения для временных и локальных файлов.

## Статус

Учебный проект. Конфигурация предназначена для изучения базовых механизмов разработки 1С.
